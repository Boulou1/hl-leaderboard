# Trader Equity PnL All Return Unrealised Realised Volume Pos Trend

Not everyone here trades on the same venue, so equity combines two sources. On Hyperliquid it is Hyperliquid’s own account value across the main order book and all builder-deployed (HIP‑3) perp DEXes; spot USDC is the same collateral backing those positions, so it is never added on top, and PnL there is net of deposits and withdrawals. On Robinhood Chain it is the wallet’s ETH plus tokens, priced from each token’s on-chain DEX pool, and PnL is rebuilt from the wallet’s full swap history — accounted in ETH, the quote asset of every pool here, and converted at the current rate. That reconstruction is checked against the wallet’s real balances; if it cannot reproduce them the PnL is withheld and shown as “—” rather than guessed at. Tokens that arrived as transfers have an unknown cost, not a zero one, so their proceeds are excluded instead of booked as pure profit.
